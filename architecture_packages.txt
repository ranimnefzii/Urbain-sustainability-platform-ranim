## Détails des Packages Backend

### 1. Core Package
- **config.py**: Gestion variables environnement, settings
- **security.py**: JWT, bcrypt, OAuth2, permissions
- **database.py**: Connection PostgreSQL/MongoDB, sessions
- **dependencies.py**: Injection dépendances FastAPI

### 2. Models Package (SQLAlchemy)
- **user.py**: Entité User (citoyen, admin, secteur)
- **signal.py**: Entité Signal (détails signalement)
- **category.py**: Entité Category (type problèmes urbains)
- **priority.py**: Entité Priority (niveaux urgence)
- **report.py**: Entité Report (rapports générés par IA)

### 3. Schemas Package (Pydantic)
- Validation des données entrantes/sortantes
- DTOs pour chaque entité
- Sérialisation/désérialisation API

### 4. API Package (FastAPI Router)
- **auth.py**: Login, register, refresh token
- **users.py**: CRUD utilisateurs, profils
- **signals.py**: CRUD signalements, géolocalisation
- **categories.py**: Gestion catégories problèmes
- **reports.py**: Rapports IA, analytics
- **admin.py**: Tableau de bord administration

### 5. Services Package (Logique Métier)
- **ai_service.py**: Classification IA, priorisation
- **notification_service.py**: Push notifications, alertes
- **email_service.py**: Emails automatiques, templates
- **map_service.py**: Intégration Google Maps, géocoding

### 6. Repositories Package (Data Access)
- Pattern Repository pour abstraction BDD
- Séparation logique métier / accès données
- Support PostgreSQL avec SQLAlchemy

## Technologies Backend

- **Framework**: FastAPI (Python 3.9+)
- **Base de données**: PostgreSQL + Redis (cache)
- **ORM**: SQLAlchemy 2.0
- **Authentification**: JWT + OAuth2
- **Validation**: Pydantic V2
- **Tests**: Pytest + Factory Boy
- **Documentation**: OpenAPI/Swagger automatique
- **Migration**: Alembic
- **Containerisation**: Docker + Docker Compose

## Architecture Patterns

- **Clean Architecture**: Séparation des responsabilités
- **Repository Pattern**: Abstraction accès données
- **Dependency Injection**: FastAPI built-in
- **Service Layer**: Logique métier isolée
- **CQRS**: Read/Write separation (si nécessaire)

## Sécurité

- JWT tokens avec refresh mechanism
- Password hashing avec bcrypt
- Rate limiting sur endpoints critiques
- CORS configuration
- Input validation avec Pydantic
- SQL injection prevention (SQLAlchemy)

## Performance

- Async/await avec FastAPI
- Redis cache pour données fréquemment accédées
- Database connection pooling
- Pagination automatique
- Background tasks pour emails/notifications

## Monitoring & Logging

- Structured logging avec Python logging
- Health checks endpoints
- Metrics avec Prometheus (optionnel)
- Error tracking avec Sentry (optionnel)
