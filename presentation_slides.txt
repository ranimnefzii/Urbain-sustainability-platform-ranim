## SLIDE 2: CONTEXTE ET PROBLÉMATIQUE

**TITRE: Contexte Urbain et Défis Actuels**

**Contenu:**
**Problématique Principale:**
- Les villes font face à une croissance rapide des problèmes urbains
- Processus de signalement manuel lent et inefficace
- Manque de priorisation automatique des urgences
- Difficulté de suivi pour les citoyens et administrations

**Statistiques Clés:**
- +30% d'augmentation des signalements urbains/an
- Délai moyen de traitement: 72 heures
- Taux de satisfaction citoyen: 45%

**Besoin Identifié:**
Système intelligent qui automatise, priorise et optimise la gestion des problèmes urbains

## SLIDE 4: ARCHITECTURE TECHNIQUE

**TITRE: Architecture Système Moderne**

**Contenu:**
**Architecture Microservices:**
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Frontend      │    │   Backend API   │    │   Services IA   │
│   React/Vue     │◄──►│   FastAPI       │◄──►│   Python ML     │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         ▼                       ▼                       ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Mobile App    │    │   PostgreSQL    │    │   Google Maps   │
│   Responsive    │    │   Redis Cache   │    │   API Services  │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

**Stack Technique:**
- **Frontend:** React/Vue.js + TailwindCSS + Google Maps API
- **Backend:** FastAPI (Python) + SQLAlchemy + PostgreSQL
- **IA/ML:** Scikit-learn + Transformers + NLP
- **Infrastructure:** Docker + Redis + Celery
- **Sécurité:** JWT + OAuth2 + Rate Limiting

**Avantages Architecture:**
- Scalabilité horizontale
- Déploiement continu
- Haute disponibilité
- Maintenance simplifiée

## SLIDE 5: INTELLIGENCE ARTIFICIELLE

**TITRE: Moteur IA de Classification**

**Contenu:**
**Algorithmes Déployés:**
1. **Classification Textuelle:** NLP pour analyse des descriptions
2. **Analyse d'Images:** Computer Vision pour photos des problèmes
3. **Calcul de Priorité:** ML multi-critères (urgence, impact, localisation)
4. **Prédiction Temps:** Estimation durée intervention

**Pipeline IA:**
```
Signalement → Extraction Features → Classification → Priorisation → Rapport
     │              │                │              │           │
   Texte         Localisation      Catégorie     Score IA    Action
   Image         Historique       Sous-type    Criticité   Recommandée
   Métadonnées   Contexte         Urgence      Temps       Secteur
```

**Modèles Utilisés:**
- BERT pour analyse textuelle
- CNN pour classification d'images
- Random Forest pour priorisation
- Time Series pour prédictions

**Performance:**
- Précision classification: 92%
- Faux positifs: <5%
- Temps de traitement: <2 secondes
